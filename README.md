
# Digital Logic Circuit Simulator

A Python-based graphical application for simulating fundamental
digital electronic circuits.

## Features

- AND, OR, NOT, NAND, NOR, XOR and XNOR gates
- Half adder and full adder
- 2:1 multiplexer
- D flip-flop with clock and reset controls
- Automatic truth table generation for combinational circuits
- Interactive graphical interface built using Tkinter

## Technologies Used

- Python 3
- Tkinter
- Git and GitHub

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run:

   python app.py
